# Blender Composite Repair Tool

Progetto sviluppato nell'ambito della tesi di Laurea Triennale in Informatica presso l'Università degli Studi di Catania.

## Descrizione

Il progetto riguarda lo sviluppo di un tool interattivo e parametrico in Blender per supportare la riparazione di strutture composite danneggiate.

A partire dalla scansione 3D della superficie danneggiata, il tool consente di generare e adattare una geometria, denominata "campana", alla superficie del componente.

La modellazione è stata realizzata principalmente attraverso Geometry Nodes e l'utilizzo di Gizmo, permettendo all'utente di modificare in maniera interattiva alcuni parametri della geometria.

Il modello ottenuto può essere successivamente prodotto tramite stampa 3D e utilizzato nel processo di riparazione della struttura composita.

## Tecnologie utilizzate

- Blender
- Geometry Nodes
- Gizmo
- Modellazione 3D
- Scansione 3D
- Stampa 3D
